# GNSS spoofing detection under multipath interference

Code and experimental dataset information for **Robust GNSS spoofing detection
under multipath interference: a multi-correlator Transformer-LSTM approach**.

- [Algorithms and execution](code/README.md)
- [Experimental datasets and parameters](dataset/README.md)

The code includes the proposed model, CNN, ResNet1D, LSTM, Transformer,
sliding Delta, WSCM and DWT-fuzzy. Self-collected recordings are available by
email request to the corresponding author. TEXBAT access links and experimental
data configurations are provided in the dataset description.
