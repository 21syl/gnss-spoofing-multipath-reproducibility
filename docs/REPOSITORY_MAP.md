# Repository map

| Manuscript evidence | Repository location | Final action required |
|---|---|---|
| Self-collected BDS B1I inputs | `data/processed/` or external DOI | Deposit model-ready data and metadata |
| Raw RF/IQ recordings | external data record | Confirm public or controlled access route |
| TEXBAT inputs | official source | Add stable source, version, and access date |
| Fixed data partitions | `data/splits/` | Replace demo rows with complete frozen manifests |
| Proposed model | `src/models/` | Add verified implementation and tests |
| Baselines | `src/baselines/` | Add all reported baseline implementations |
| Training configurations | `configs/` | Freeze every manuscript experiment configuration |
| Figures and tables | `results/` and `scripts/` | Add source data and deterministic generators |
| Software environment | `environment/` | Pin exact versions and validate on a clean system |
