# Source code

Suggested modules:

- `models/`: complete proposed network and ablation variants
- `baselines/`: deep-learning and traditional SQM baselines
- `data/`: loading, preprocessing, normalization, and leakage-safe grouping
- `training/`: deterministic training and checkpoint management
- `evaluation/`: metrics, ROC/AUC, confusion matrices, latency, and resource reporting
